\section{Introducción}

\begin{frame}{Definición}
  Un hash es una representación de tamaño fijo de otro objeto.

  \medskip
  Sirve para:
  \begin{itemize}
    \item comparar dos objetos en \(O(1)\),
    \item usarlo como clave de un arreglo o de un diccionario,
    \item hacer sobre el hash una cuenta que imita una operación del objeto.
  \end{itemize}
\end{frame}
